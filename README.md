## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Connect to micro:bit  
「micro:bit と接続する」をタップして BBC micro:bit と接続します。micro:bit 側の Bluetooth は public に設定してあるのでどの端末からでもペアリング可能です。

## control robot  
「「A」を送信」、「「B」を送信」または「「C」を送信」をタップするとロボットが任意の動作をします。停止させる場合「「Z」を送信」をタップしてください。
